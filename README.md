# Sales Executive Performance Dashboard

An interactive Power BI dashboard designed to analyze sales performance, profitability, and operational efficiency.

## Preview
![Dashboard Visual](Sales%20Executive%20Performance.jpeg)

## Key Insights & Features
* **Executive KPIs**: Real-time tracking of Sum of Sales ($2.33M), Sum of Profit ($292.30K), and Sum of Quantity (39K).
* **Regional Analysis**: Performance breakdown across Central, South, East, and West regions.
* **Managerial Tracking**: Monitoring top-performing area managers such as Sadie Pawthorne and Chuck Magee.
* **Sales Trends**: Yearly sales progression analysis from 2023 to 2026.
* **Target Achievement**: Visual gauge for sales target monitoring.

## Tools Used
* **Power BI Desktop**: Data modeling and visualization.
* **Dataset**: Sales transaction records.
